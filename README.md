# Лабораторная работа №3. Циклы с ветвлениями

**Вариант:** 24

## Задание

Вычислить произведение \(Pe \cdot D\) и число Нуссельта \(Nu\) для длин трубы 5, 10, 20, 50 и 100 м, используя заданные формулы.

## Исходные данные

- Скорость движения жидкости: \(w = 0{,}3\) м/с.
- Кинематическая вязкость: \(\nu = 9{,}5 \cdot 10^{-3}\) см²/с.
- Диаметр трубы: \(d = 18\) мм.
- Температуропроводность: \(\alpha = 3 \cdot 10^{-3}\) см²/с.

Перед вычислениями величины переводятся в согласованные единицы измерения.

## Описание программы

Программа получает исходные данные с клавиатуры, вычисляет числа Рейнольдса \(Re\) и Пекле \(Pe\). С помощью цикла `for` последовательно обрабатываются пять длин трубы. На каждой итерации вычисляются безразмерный диаметр \(D\), произведение \(Pe \cdot D\) и число Нуссельта \(Nu\). Для выбора формулы используется условный оператор `if/else`.

## Ввод и запуск

1. Скомпилировать и запустить программу.
2. Ввести скорость движения жидкости в см/с: `30`.
3. Ввести кинематическую вязкость в см²/с: `0.0095`.
4. Ввести диаметр трубы в см: `1.8`.
5. Ввести температуропроводность в см²/с: `0.003`.
6. Последовательно ввести длины трубы в метрах: `5`, `10`, `20`, `50`, `100`.

## Результат

Программа выводит для каждой длины трубы значения произведения \(Pe \cdot D\) и числа Нуссельта \(Nu\).
